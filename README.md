# MoodLog（情绪猫）

本地优先的情绪记录 App：记录情绪、强度、标签与备注，并通过日历、洞察和情绪卡片回看自己的状态。

## 主要功能

- 8 类核心情绪快速打卡，支持强度、活动标签和备注。
- 日历、记录列表与日/周/月/季/年统计洞察。
- 情绪卡片生成，可保存到相册或分享。
- CSV / JSON 数据导出。
- 累计 200 条记录后开启情绪图书馆，以 8 本情绪集呈现每日记录。
